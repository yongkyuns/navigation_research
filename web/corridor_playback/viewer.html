What you are comparing
Raw EKF uses only the original IMU/GNSS inputs. Independent map treats the marginal map error separately at each accepted cell. Correlated map retains shared map uncertainty and its correlation with navigation.
The map is a finite-width road corridor, not a lane-center target. Both map arms receive the same proposed geometry and support schedule. A missing map measurement leaves the persistent corrected state running.
This is a fixed-map Schmidt-style approximation with one experimental extract-wide translation. Smaller correction steps or closer map alignment are not measured accuracy. Exact per-update line/fillet geometry was not retained; the map shows the supplied road graph.

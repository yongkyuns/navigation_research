# Qualified road-corridor comparison viewer

This viewer renders **existing verified PR #13 native replay evidence**. It does
not run, tune, interpolate, or smooth an estimator. The original seven-sigma
centerline experiment at `docs/index.html` remains unchanged. The new standalone
page is intended for `docs/corridor.html` after its generated bytes are reviewed
and committed through the normal pull-request process.

## What is visible

Raw IMU/GNSS EKF (blue circles), independent-map-noise EKF (cyan squares), and
correlated-map-error EKF (green triangles) share the same clock and camera. All
four recordings are available. Overlay and three-panel layouts, sample stepping,
seeking, speed, pan/zoom, follow mode, CSV export and covariance ellipses operate
on the retained numerical samples. The metre-scale displacement inset makes
sub-metre changes visible without changing the map trajectories. “Model
difference” jumps to the largest separation of the two corrected estimators;
“Largest map step” is a different statistic and has its own button.

Purple is the original selected graph edge, not a position estimate. Separate
sampled timelines display original association, connected geometric support,
new measurements in each arm, and continuous initialized position output.
Missing map measurements do not hide the corrected trajectory. Pre-initialization
positions are absent, not replaced with GNSS or a later initialized sample.

This evidence contains **one fixed qualified preset**, correction sigma 0.25 m
and shared map sigma 1.5 m. No live sigma slider is invented. The old seven-sigma
experiment remains linked separately. The input graph contains 7,333 directed
edges. Per-update fitted line/fillet geometry was not retained; the viewer does
not falsely label the input polyline as that exact fitted factor.

The page is self-contained: no map service, remote scripts, fonts, network
requests, gzip, or streaming-decompression dependency. A real static SVG overview
remains when scripts are unavailable. A restricted preview still may prevent
interactive scripts, but it need not show a blank map.

## Reproduce

With the retained artifact (or `artifacts/corridor-playback-pr13-ci.zip` once
staged into this repository):

```sh
export CORRIDOR_ARTIFACT=/path/to/pr13-b3ee9b3-current-ci.zip
python -m pytest -q web/corridor_playback/tests
python web/corridor_playback/build.py --artifact "$CORRIDOR_ARTIFACT" --output /tmp/corridor.html
python -m pip install playwright==1.57.0
python -m playwright install chromium
python web/corridor_playback/browser_check.py --html /tmp/corridor.html --output /tmp/corridor-browser-checks
```

`--browser-executable /usr/bin/chromium` is available for system Chromium.
Local tests use `set_content` to inspect the actual HTML without a server and
also load it as sandboxed iframe `srcdoc`. The source has no runtime data fetch.

## Publication boundary

The new workflow first verifies the exact archived evidence, builds/tests the
page, and exercises Chromium. **Only after all tests succeed**, it stages the
HTML and original evidence ZIP as immutable Git blobs. It creates no commit,
changes no branch reference, and performs no deployment. Its returned object IDs
and hashes allow a later guarded PR commit to attach those exact bytes, without
pasting or silently regenerating a large page.

Before merge, attach `docs/corridor.html` and
`artifacts/corridor-playback-pr13-ci.zip` from `ready-to-commit.json`, recheck source
head and byte hashes, and require fresh current-head CI. The second run uses the
retained archive from the repository (so evidence expiration is not a permanent
build dependency), regenerates the page and checks byte identity. The original
`docs/index.html` SHA-256 is enforced. Main/docs Pages configuration is unchanged.
No website is live merely because the source PR or a build artifact exists.

Local browser coverage includes all four recordings in both layouts, 40 exact
sample/diagnostic checks including initialization and post-correction association
gaps, all 1,569 CSV rows, real export download, playback/pause, sample stepping,
camera controls, overlays, mobile overflow, restricted iframe, script-disabled
fallback and zero page/console errors or network requests. Native estimator
qualification is the pinned PR #13 evidence, not a new execution in this UI pass.

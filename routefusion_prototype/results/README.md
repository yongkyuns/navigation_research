# Published reproduction evidence

These are fresh synthetic runs of the unchanged original code, not byte-identical copies of the original chat traces. All primary navigation metrics and summaries match the preserved originals within 1e-9 absolute/relative tolerance. A nearest-road diagnostic in the exactly symmetric scenario can break ties differently across CPUs; any such difference is separately recorded and accepted only after all 120 positions are checked on the exact bisector and all route outputs remain ambiguous. Runtime, environment, test logs, replay files, tiles and the figure were produced during this publication. No historical timings were substituted.

The exact original numerical records are in ../../provenance/original-metrics.json and original-summary.json; the original report/code are checksum-verified. The historical project README and validation report describe the original study. Use the root README for safe, non-overwriting reruns.

Six replay cases (720 outputs) and the original 24 algorithm tests are checked. No hardware or real-city dataset evaluation is claimed.
